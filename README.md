# .github

Default community health files for every repository in Nothing-Technology-Limit. A repository that
has its own copy of a file uses its own; every other repository uses the one here.

| File | Used as |
|---|---|
| `CONTRIBUTING.md` | how a change reaches a repository |
| `SECURITY.md` | how to report a security problem |
| `.github/pull_request_template.md` | the body a new pull request starts with |

This repository is public because GitHub reads default files only from a public `.github`
repository. Nothing internal goes here. Members-only information is in `.github-private`.
